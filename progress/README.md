# EpayNepal — Progress Tracking System

> This folder tracks the development status of every phase, task, bug, and improvement across the entire project.

## How to Read This

Each phase file (`phase_XX.md`) contains a checklist of tasks. Status indicators:
- `⬜ Not Started` — No work begun
- `🟨 In Progress` — Actively being worked on
- `🟩 Completed` — All tasks verified complete
- `🟥 Blocked` — Cannot proceed (see notes)

Individual task format:
```
- [ ] Task description → false     (not done)
- [x] Task description → true      (verified complete)
```
